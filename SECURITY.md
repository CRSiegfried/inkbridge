# Security Policy

## Supported versions

inkbridge is pre-alpha (`0.1.0`). Only the latest `master` is supported;
please confirm an issue reproduces there before reporting.

## Reporting a vulnerability

Please report security vulnerabilities **privately** — do not open a public
issue, PR, or discussion for anything security-sensitive.

Use GitHub's private vulnerability reporting: open the repository's
[Security tab](https://github.com/CRSiegfried/inkbridge/security) and choose
**"Report a vulnerability,"** or go straight to
[the advisory form](https://github.com/CRSiegfried/inkbridge/security/advisories/new).
This keeps the report private to the maintainer until a fix is ready and lets
us coordinate a disclosure and (if warranted) a CVE.

## What to expect

- An acknowledgement, typically within a few days.
- A follow-up with an assessment and, if accepted, a fix timeline.
- Credit in the advisory when a fix ships, unless you'd rather stay anonymous.

Thanks for helping keep inkbridge and its users safe.
